# Accessibility requirements

Baseline: [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/) and relevant [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/), preferring native semantics.

Implemented: skip link and landmarks; native keyboard controls with no drag-only action; visible focus; live trial/error announcements; exact captioned data tables; described SVG graphs; optional and stoppable sonification duplicated by text; persistent contrast/text/motion/audio preferences; labelled modal; responsive reflow; and no essential color-only state.

Manual testing is still required with current NVDA/Firefox, NVDA/Chrome and VoiceOver/Safari. Record versions, tasks, focus order and failures. Blind and low-vision learner research requires informed consent; blindfolded testing is not equivalent.
