# Testing and verification

`npm run check` performs syntax checks, source-quality rules, eleven scientific and assessment tests, and a production build. GitHub Actions repeats the gate and audits high-severity production dependencies.

Manual release protocol: complete all experiments without a pointer; verify trial and error announcements with a screen reader; compare table, graph and sound; save/reload/export/delete notebook data; revisit offline after one online load; inspect 200% zoom and 320-pixel reflow; verify contrast, large text and reduced motion.

Automated science evidence is implemented. Human assistive-technology and blind/low-vision participant findings must be recorded only after they actually occur.
